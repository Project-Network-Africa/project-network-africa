# PNA2 Frontend

Frontend application for the **PN Africa Website Development** project.

## Project Overview

This repository contains the frontend codebase for the PN Africa website. It is built with Next.js and TypeScript, following a component-based architecture to support scalability and maintainability.

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- ESLint
- Git & GitHub
- Vercel (Deployment - Pending)

## Prerequisites

Before running the project, ensure you have:

- Node.js (v20 or later recommended)
- npm

## Getting Started

### Clone the repository

```bash
git clone https://github.com/PN-Africa/pna2-frontend.git
```

### Navigate into the project

```bash
cd pna2-frontend
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The application will be available at:

```
http://localhost:3000
```
